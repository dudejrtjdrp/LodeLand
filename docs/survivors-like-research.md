# 뱀서라이크 히트작 시스템 분석 & moveSword 적용 제안

> 작성일: 2026-08-14
> 대상: moveSword (Phaser 3 기반, 검 궤도·발사형 뱀파이어 서바이버류)
> 분석 게임: Vampire Survivors, Brotato, 20 Minutes Till Dawn, Halls of Torment, HoloCure, Death Must Die (+참고: DRG: Survivor, Soulstone Survivors, 탕탕특공대)

---

## 1. 요약 (TL;DR)

성공한 뱀서라이크들의 공통 뼈대는 **"이중 성장 루프"** 다.

- **런 안**: 수십 초마다 의미 있는 선택(레벨업 3~4택) → 시너지 발견 → 화면을 채우는 파워 판타지 → 정점에서 극적으로 끝나는 런.
- **런 밖**: 실패해도 반드시 남는 것(골드/업적/언락) → 영구 강화 → "한 판 더".

moveSword는 현재 **검 궤도-발사라는 훌륭한 차별화 코어**를 갖고 있지만, 위 루프의 핵심 부품이 대부분 비어 있다. 최우선 추가 대상은:

1. **레벨업 선택 UI (3택)** — 장르의 심장. 이것 없이는 뱀서라이크가 아님
2. **분 단위 웨이브 테이블 + 엘리트/보스 + 런 종료(사신)** — 런의 기승전결
3. **검 합성/진화** — 이미 있는 검 8종 카탈로그를 조합 콘텐츠로 전환
4. **골드 + 영구 업그레이드 + 언락** — 리텐션의 근간
5. **타격감(juice) 강화** — 히트스톱, 넉백, 픽업 연출

## 2. 게임별 핵심 시스템 분석

### 2-1. Vampire Survivors — 장르의 원형 (약 600만 장, Steam 98% 긍정, BAFTA 2관왕)

1인 개발(Luca Galante), 심지어 **moveSword와 같은 Phaser로 시작**한 게임. $2.99 얼리액세스로 출발해 매출 약 $2,000만.

**레벨업 선택**: 기본 3택, Luck 스탯에 따라 4번째 선택지 확률 등장. 무기 6칸 + 패시브 6칸 상한. **리롤/스킵/배니시**는 골드로 사는 소모성 자원 — 선택 조작 자체가 메타 성장 대상.

**무기 진화(Evolution)**: 이 게임 최대의 발명. `무기 최대 레벨(8) + 지정 패시브 보유 + 보스 상자 개봉` = 상위 무기로 변신. 예: Whip + Hollow Heart → Bloody Tear. 무기+무기를 합쳐 슬롯을 비우는 **합체(Union)** 도 존재. 레시피가 숨겨져 있어 **발견 자체가 콘텐츠**가 되고, 위키를 뒤지는 커뮤니티 활동이 리텐션으로 이어짐.

**메타 진행**: PowerUp 메뉴 28종(Might +5%/랭크, Amount 투사체+1 = 5,000골드, Revival 10,000골드 등). 살수록 비싸지고, **언제든 전액 환불(리스펙) 가능** → 실험 장려. 캐릭터 약 50종은 "업적 달성 → 골드 구매"의 2단계 언락.

**런 구조**: 30분 제한. 매 분마다 적 종류·스폰 밀도가 바뀌는 **분 단위 웨이브 테이블**, 정해진 시각의 엘리트/보스. 30:00에 즉사급 **사신(Reaper)** 스폰으로 런을 파워 정점에서 강제 종료 — "지쳐서 끝나는 게 아니라 극적으로 끝난다".

**픽업/맵 오브젝트**: 횃불 파괴 → 치킨(회복)/로자리(전멸)/버큠(전체 XP 흡수)/골드. 보스 상자는 1/3/5개 랜덤 내용물 + **슬롯머신 릴 연출**(개발자의 슬롯머신 업계 경력 이식).

**스탯 폭**: Might, Cooldown, Area, Amount, Duration, Speed, Luck, Growth, Greed, **Curse(적을 강화해 파밍을 가속하는 셀프 난이도)** 등 15종+.

### 2-2. Brotato — 웨이브+상점 경제 루프 (누적 1,000만 장+)

**웨이브 구조**: 총 20웨이브, 첫 웨이브 20초 → 최대 60초(보스전 90초). 웨이브 사이에 **상점 화면**으로 완전히 전환. "짧은 긴장 → 짧은 보상 결정"의 고밀도 루프로 한 런 20~30분.

**상점**: 아이템 4개 진열, 리롤 비용이 웨이브에 비례해 상승, **잠금(Lock)** 으로 다음 웨이브까지 가격 동결 예약 가능. "지금 살까, 아낄까"의 경제 게임이 매 웨이브 반복됨.

**재료 = XP + 골드 통합**: 적이 떨어뜨리는 재료 하나가 경험치이자 화폐. 모든 전투 행동이 구매력으로 직결되는 단일 자원 설계.

**무기 합성**: 6슬롯, **같은 무기 같은 티어 2개 → 상위 티어 1개**. 단순하지만 "같은 무기를 모은다"는 수집 동기가 강력.

**캐릭터 = 규칙 변형**: 62종의 캐릭터가 스탯 보정이 아니라 게임 규칙을 바꿈(Bull: 무기 장착 불가, Pacifist: 데미지 -100% 대신 생존 보상, Multitasker: 무기 12칸). 캐릭터 하나가 사실상 새 게임.

**난이도**: 위험도(Danger) 0~5. 각 위험도 첫 클리어가 캐릭터 언락 조건 → 62캐릭터 × 6위험도의 도전 매트릭스.

### 2-3. 20 Minutes Till Dawn — 능동 조작 + 시너지 트리 (첫 4일 22만 장)

**차별점 하나에 집중**: VS의 자동 공격 대신 **수동 조준·사격·재장전**. 장전 타이밍이 빌드 재료가 되는 캐릭터(Luna: 재장전 시 블랙홀)까지 존재.

**업그레이드 트리**: 25개 트리 × 4단계 = 100개 업그레이드. 특정 조합을 갖추면 **시너지 카드**가 등장(빙결+화상 → Frost Fire). 작은 퍼크들이 상태이상을 매개로 엮이며 빌드가 "발견"됨.

**시작 조합**: 캐릭터 13 × 무기 13 = 169 시작 조합. 런 시작 전 선택도 콘텐츠.

**메타**: 룬을 사되 **장착 슬롯 제한(공격 1 + 방어 1)** 으로 영구 성장에도 선택압 유지. 난이도는 다크니스 0~15 누적 페널티.

### 2-4. Halls of Torment — "업적이 곧 콘텐츠" (100만 장+, $4.99)

**퀘스트 500개**가 단순 도전과제가 아니라 캐릭터·어빌리티·특성·장비·스테이지를 여는 언락 트리. 게다가 **완료 퀘스트 1개당 XP +0.5% 영구 보너스** — 수집 자체가 전투력이 됨. 캐릭터 14종의 언락 조건("Ember Grounds에서 1,000킬")이 곧 플레이 가이드 역할.

**장비 + 우물**: 런 중 주운 장비를 **우물에 던져 송환해야 영구 보관**(송환하면 남은 런 동안 못 씀 — 리스크/리워드). ARPG식 장비 슬롯 7개.

**어빌리티 분기**: 무기 진화 대신, 어빌리티가 특정 레벨에서 **분기형 특성 중 택1**로 작동 방식이 변형.

### 2-5. HoloCure — 조합 축의 곱셈 (무료, Steam 99% 긍정)

**콜라보 무기**: 최대 레벨 무기 2개 + 골든 모루 → 상위 무기 1개(25종). **스탬프**(무기당 3개 장착, 22종)와 **인챈트**(랜덤 옵션 부여)로 조합 축을 계속 곱함: 무기 × 콜라보 × 스탬프 × 인챈트.

**생활 메타**(Holo House): 낚시·농사·요리가 본편 런 버프로 환류. 재화(HoloCoin)의 쓸 곳을 다층화(가챠·상점·인챈트·가구)해 파밍 동기가 마르지 않음.

### 2-6. Death Must Die — 레벨업을 감정적 이벤트로 ($6.99 얼리액세스 히트)

**신 축복 시스템**: 레벨업 시 Hades처럼 **신이 강림해 축복 3택**을 제시. 같은 "3택 1"이라도 연출과 서사로 감정적 순간으로 격상. 축복에 5단계 레어리티(Novice→Legend)가 있어 레벨업 자체가 뽑기의 긴장감을 가짐.

**루팅 보존**: 런 성패와 무관하게 **주운 장비는 전부 캠프 창고에 남음**. "죽어도 오늘 전리품은 남는다"가 매 런의 최소 보상을 보장.

### 2-7. 참고 3종

- **DRG: Survivor**: 파괴 가능한 지형(벽 뚫기 = 이동/방어 수단) + 무기 마스터리(무기별 레벨업이 영구 해금으로) → "이번 런에 이 무기를 키울 이유"를 메타가 부여.
- **Soulstone Survivors**: 난이도를 플레이어가 저주(Curse) 중첩으로 직접 쌓는 구조 — "빌드 최적화 → 더 많은 저주 감당"의 상향 나선.
- **탕탕특공대(Survivor!.io)**: 스킬 5성 + 지정 서포트 스킬 = 진화. 한 런 안의 "레시피 완성"이라는 명확한 중간 목표. 모바일 월 $500만 매출 추정.

## 3. 장르가 작동하는 이유 (설계 원리)

1. **이중 루프**: 런 내 성장(초 단위 도파민) × 런 밖 영구 성장(실패 보험). "어떤 런도 낭비가 아니다"라는 신호가 항상 켜져 있어야 한다.
2. **결정 케이던스**: 조작 난이도가 아니라 **선택 밀도**로 몰입을 만든다. 레벨업 선택이 30초~1분 간격으로 계속 발생해야 함.
3. **스파이럴 감정 곡선**: 초반(생존 압박) → 중반(빌드 최적화) → 후반(화면 지배)으로 같은 행동의 감정이 계속 변해야 한다. 이 곡선이 평평하면 "같은 10분의 반복"으로 느껴진다.
4. **니어미스 효과**: 명확한 결승선(30분/20웨이브)이 있어야 "28분에 죽은 런 = 거의 이겼다"는 재도전 충동이 생긴다.
5. **시너지 발견 = 콘텐츠**: 숨겨진 레시피(진화/콜라보/시너지 카드)는 발견 자체가 콘텐츠고, 위키·커뮤니티 활동을 만든다.
6. **탄막 역전 판타지**: 화면을 가득 채우는 이펙트와 수백 마리 동시 처치가 스펙터클 그 자체로 보상. **타격감(juice)이 빈약한 클론이 실패하는 1순위 이유**.
7. **런은 반드시 끝난다**: 끝이 없으면 파워 정점이 아니라 피로에서 세션이 끝난다.

**실패한 클론들의 공통 함정**: 빌드 다양성 부족(조합이 곱셈으로 늘지 않음), 피드백 부족, 메타 진행 부재, 평평한 감정 곡선, 런 종료 설계 부재.

## 4. moveSword 현재 상태 진단

| 영역 | 현재 상태 | 히트작 기준 갭 |
|---|---|---|
| 코어 차별화 | ✅ 검 궤도→발사→귀환 (독창적, 20MTD의 "능동 차별점 1개" 원칙에 부합) | 궤도 자체를 빌드 축으로 아직 활용 안 함 |
| 레벨업 | ❌ 고정 레벨(2/4/6/8/10)에서 검 자동 추가 | **선택지가 전혀 없음** — 장르 핵심 부재 |
| 무기 시스템 | 🔶 검 8종 카탈로그(데이터 주도 설계 좋음) | 합성/진화/조합 없음, 획득 순서 고정 |
| 패시브/스탯 | ❌ 크리티컬만 존재 | 스탯 축 자체가 없음 |
| 적/웨이브 | ❌ 적 1종, 스폰 간격만 감소 | 웨이브 테이블·엘리트·보스 없음 |
| 런 종료 | ❌ 죽을 때까지 무한 | 타이머/사신/승리 조건 없음 |
| 픽업 | 🔶 XP 오브 + 자석만 | 치킨/로자리/버큠/상자 없음 |
| 메타 진행 | ❌ 없음 | 골드·영구 업그레이드·언락·업적 전무 |
| 타격감 | 🔶 데미지 텍스트, 틴트 있음 | 히트스톱·넉백·화면 흔들림·처치 연출 부족 |

이미 잘 갖춘 것: 데이터 주도 카탈로그 구조(enemyCatalog/swordCatalog/templates.json), 오브젝트 풀링, 궤도 시스템의 상태 기계(orbiting/launching/returning). **새 시스템을 얹기 좋은 토대**다.

## 5. 추천 시스템 (우선순위별)

### P0 — 이것부터 (장르 성립 요건)

**① 레벨업 3택 선택 UI**
- 출처: 전 게임 공통. 게임을 일시정지하고 카드 3장 제시.
- moveSword 적용: 선택지 풀 = `새 검 추가` / `보유 검 강화(데미지·쿨다운·maxHits)` / `패시브 스탯`. 지금의 "고정 레벨에 검 자동 추가"를 이 UI로 대체.
- 구현 포인트: `upgradeCatalog.json` 신설(기존 데이터 주도 패턴 유지), `scene.physics.pause()` + 오버레이 UI. 선택지 가중치에 Luck 스탯 반영은 나중에.
- 이후 확장: 리롤/배니시 버튼(VS), 시너지 카드 등장 조건(20MTD).

**② 분 단위 웨이브 테이블 + 엘리트/보스 + 런 종료**
- 출처: VS(분 단위 테이블 + 30분 사신), Brotato(20웨이브 명확한 결승선).
- moveSword 적용: `waveTable.json` — 분마다 적 구성·스폰 간격·최소 유지 마릿수 정의. 5분마다 엘리트(대형+체력바), 10/20분에 보스. **15~20분 제한 + 시간 종료 시 즉사급 사신 스폰**(첫 버전은 15분 권장 — 콘텐츠 양에 맞는 짧은 결승선).
- 근거: 니어미스 효과와 스파이럴 곡선은 명확한 결승선 없이는 성립하지 않음. 적 카탈로그가 이미 다중 적을 지원하므로 적 3~4종만 추가하면 됨(templates.json에 goblin/boss 예제도 이미 있음).

**③ 타격감(Juice) 패스**
- 출처: 장르 실패 요인 1순위가 피드백 부족.
- moveSword 적용: 검 적중 시 **히트스톱(30~60ms)**, 넉백, 적 흰색 플래시(이미 hit 애니메이션 있음 → 틴트 플래시 추가), 처치 시 파티클 + 미세 화면 흔들림, 엘리트 처치 시 큰 연출. XP 오브 획득음/레벨업 사운드.
- 비용 대비 효과가 가장 큰 작업. VisualEffectsSystem이 이미 있어 확장 지점 명확.

### P1 — 차별화와 리텐션 (P0 다음 마일스톤)

**④ 검 합성/진화 시스템**
- 출처: Brotato(같은 무기 2개 → 상위 티어), VS(무기+패시브+상자 → 진화), HoloCure(콜라보), 탕탕특공대(스킬+서포트 → 진화).
- moveSword 적용 제안 (2단계):
  - 1단계(Brotato식, 구현 쉬움): 레벨업에서 같은 검을 또 선택하면 **같은 검 2자루 → 상위 검 1자루로 합성**. 기존 8종 카탈로그가 그대로 티어 사다리가 됨 (bronze×2 → rusty … → obsidian).
  - 2단계(VS식, 콘텐츠 깊이): 특정 검 + 특정 패시브 → **숨겨진 진화검**(예: Ruby Sword + 크리티컬 패시브 → 화염 궤적을 남기는 진화검). 레시피를 숨겨서 발견 콘텐츠로.
- 근거: 조합 축이 곱셈으로 늘어야 빌드 다양성이 생김. 현재 검 8종은 "순서대로 강해지는 사다리"일 뿐 조합이 아님.

**⑤ 패시브 아이템 + 스탯 시스템**
- 출처: VS 스탯 15종, Brotato 스탯 15종.
- moveSword 적용: 검 6자루 + 패시브 6칸 구조 권장. **궤도 게임 전용 스탯**이 차별화 기회:
  - 공통 스탯: 데미지%, 쿨다운%, 이동속도, 최대체력, 회복, 자석 범위, XP 획득%
  - **궤도 전용 스탯: 궤도 반경(radius), 궤도 회전 속도(orbitSpeed), 발사 속도(launchSpeed), 스캔 범위(scanRadius), 동시 발사 수, 귀환 속도** — SwordOrbitSystem의 옵션들이 이미 전부 변수로 존재하므로 스탯화 비용이 낮음.
  - 20MTD가 "재장전"을 빌드 재료로 만들었듯, **"궤도"를 빌드 재료로**: 넓은 궤도 방어형 빌드 vs 좁고 빠른 궤도 근접 빌드 vs 발사 특화 포탑 빌드.
- Curse류 스탯(적 강화로 파밍 가속)은 후순위로 추가 가치 높음.

**⑥ 골드 + 영구 업그레이드 + 언락**
- 출처: VS PowerUp(전액 환불 가능), HoT 축복, 20MTD 룬.
- moveSword 적용: 적 처치·상자에서 골드 → 메인 메뉴 영구 업그레이드(데미지/체력/이동속도/시작 검 +1 등 8~10종으로 시작). **환불 자유** 필수(실험 장려, VS·HoT 공통). localStorage 저장.
- 언락: 시작 검 선택권(업적 달성 → 골드 구매), 이후 캐릭터 추가. "X 처치 → Y 언락" 조건은 곧 플레이 가이드(HoT 원리).

**⑦ 픽업/맵 오브젝트 + 보물상자**
- 출처: VS.
- moveSword 적용: 엘리트/보스가 **보물상자** 드랍(진화 재료 + 골드, 개봉 연출에 투자 — VS 슬롯 연출의 교훈), 필드 오브젝트(횃불 등) 파괴 → 치킨(회복)/자석(전체 흡수)/폭탄(화면 전멸) 랜덤 드랍. 오브 풀링 패턴 그대로 재사용 가능.

### P2 — 장기 확장 (콘텐츠 볼륨)

**⑧ 캐릭터 시스템 — 규칙을 바꾸는 특성** (Brotato 원리): "검이 궤도에서 절대 발사되지 않는 대신 궤도 데미지 2배", "검 1자루 고정, 모든 강화가 그 검에 집중", "궤도가 타원/8자" 등. 스탯 보정이 아니라 궤도 규칙 변형으로.

**⑨ 난이도 단계** (Brotato Danger 0~5): 클리어 시 다음 단계 + 언락 보상. 캐릭터 × 난이도 매트릭스가 콘텐츠 볼륨을 곱셈으로.

**⑩ 업적 = 콘텐츠 트리** (HoT): 업적 완료마다 소소한 영구 보너스(XP +0.5%식)를 얹으면 수집이 전투력이 됨.

**⑪ 엔드리스 모드 + 주간 시드** 등은 코어 루프 완성 후.

## 6. 제안 로드맵

```
마일스톤 1 "장르 성립" (P0)
  레벨업 3택 UI → 웨이브 테이블 + 적 3종 추가 → 엘리트/보스 1종
  → 15분 타이머 + 사신 → 타격감 패스
  목표: "한 판이 기승전결을 가진 게임"

마일스톤 2 "빌드의 탄생" (P1 ④⑤)
  검 합성(같은 검 2→상위) → 패시브 6종 + 궤도 스탯
  → 숨겨진 진화검 2~3종
  목표: "두 판이 서로 다른 게임"

마일스톤 3 "한 판 더" (P1 ⑥⑦)
  골드 → 영구 업그레이드 10종(환불 가능) → 보물상자 + 픽업
  → 언락 조건식 업적 10개
  목표: "죽어도 남는 게 있는 게임"

마일스톤 4 "콘텐츠 곱셈" (P2)
  캐릭터 2~3종(규칙 변형) → 난이도 3단계 → 업적 트리 확장
```

각 마일스톤이 끝날 때마다 검 궤도라는 차별점이 빌드 시스템과 더 깊게 엮이는 방향(⑤의 궤도 전용 스탯, ⑧의 궤도 규칙 변형)이 moveSword만의 정체성을 만든다. VS도 Phaser로 시작해 $2,000만 매출을 낸 장르다 — 토대는 이미 좋다.
