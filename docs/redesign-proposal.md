# moveSword 리디자인 제안서

> 2026-08-25. 구현 착수 전 제안 문서.
> 목표: "검을 투사체로 발사한다"는 핵심 메커니즘에서 출발한 고유 세계관·스토리·비주얼 정체성 수립,
> 그리고 그것을 실제 빌드에 반영.

## 1. 현재 프로젝트 분석

**기술 스택**: Phaser 3.90 + TypeScript + Vite. 데이터 주도 설계(catalog JSON 11종). 총 ~12,600줄.

**플레이 흐름**: Boot → Title → CharacterSelect(캐릭터 4종 + 난이도 0~2) → GameScene.
GameScene 안에서 60라운드 목표제(처치 수/사냥/생존/정예/중간보스/보스) 진행,
라운드 사이 상점(스탯 구매·검 구매·칸 해방·강화·특성 소켓), 레벨업 시 4지선다 업그레이드 카드.
메타 진행(골드 → 영구 강화 9종, 캐릭터 해금)과 결과 화면까지 완결된 루프.

**검 시스템(핵심)**: 검 8칸 궤도 선회 → 주변 적 자동 스캔 → 자동 발사(다단 히트) → 자동 귀환.
검 11종(기본 8 + 진화 3), 원소 5종, 같은 원소 2자루 = 공명(효과 1.5배), 고레벨 세트 = 필살기.
같은 검 2자루 = 상위 티어 자동 합성, 숨은 레시피 = 진화(접쇠). 창고(reserve) + 드래그 장착/교체.
칸(슬롯) 경제: 해방 → 확률 강화(+10) → 특성 소켓 3개(각인 12종).

**적**: 15종(근접/신속/중장/원거리/분열/자폭/힐러/방패/정예/중간보스 4/보스 2/사신).
전부 Skullwolf 시트 1장을 틴트만 바꿔 공유.

**UI**: theme.ts에 다크 브라운+골드 오나먼트 "중세 판타지 디자이너 시안" 테마.
Cinzel(로마 세리프) 디스플레이 폰트. HUD·상점·레벨업·일시정지·결과 화면이 테마 헬퍼 공유.

**발견한 문제(기준선)**:
- 적 애니메이션 생성 버그: `texture.width`가 undefined → framesPerRow가 NaN → 적이 1프레임 정지 상태.
- `AugmentSystem.ts`(1,319줄, 증강 39종)가 작성만 되고 게임에 **미연결**. 타입 오류 10건 전부 이 파일.
- HUD 우하단 "소모품 슬롯"은 기능 없는 가짜 UI(비주얼 전용).
- `src/systems/ShopSystem.js`(구버전 JS)는 어디서도 import되지 않는 죽은 파일.
- 명칭이 임시(Bronze/Ruby/Gold Sword, Skullwolf, Death Lord…) — 세계관 부재.
- 이모지 아이콘 혼용(💀⚔️🍀❤️…) — 화풍 불일치, 플랫폼별 렌더 차이.

## 4. 세계관 콘셉트 3안

### 콘셉트 A — 《쇳깃》 (매사냥 · 살아있는 금속) ★추천

1. **콘셉트명**: 쇳깃 (Iron Plume)
2. **한 문장**: 검은 길들인 맹금이다 — 당신은 검떼를 몰아 녹(綠)을 사냥하는 마지막 떼지기다.
3. **세계의 핵심 법칙**: 이 세계의 금속은 정련되면 "심(心)"이 깃들어 살아 움직인다. 심 있는 금속은 자맥(磁脈)의 흐름을 타고 날며, 길들이면 주인의 자장 궤도에 홰를 튼다.
4. **검을 발사할 수 있는 이유**: 발사가 아니라 **사냥**이다. 매사냥꾼이 매를 놓아주듯, 길들인 칼새는 사정거리에 든 먹잇감을 스스로 덮치고(자동 조준의 서사적 근거), 홰(궤도)로 귀소한다. 떼지기는 조준하지 않는다 — 무리를 고르고, 먹이고, 언제 풀지 결정할 뿐이다(이 장르의 실제 플레이 동사와 정확히 일치).
5. **검의 정체와 기원**: 대정련 시대에 만들어진 "심 있는 강철"의 후예들. 혈통(원소)별로 사냥 방식이 다르다. 진화(접쇠)는 두 혈통을 화로에서 겹쳐 벼리는 것.
6. **적의 정체**: **녹(綠)** — 대정련이 버린 광재에서 태어난 살아있는 부식. 정련된 금속(=심)을 먹어야 번식하며, 고철 짐승의 뼈대를 뒤집어쓰고 움직인다. 화로심장을 단 떼지기와 그의 검떼는 **세상에 남은 가장 큰 먹이** — 무리가 플레이어에게 몰려드는 이유가 규칙에서 나온다.
7. **플레이어의 목표**: 자맥길을 따라 맥터(node)를 하나씩 되찾으며(=라운드) 녹의 발원지로 향한다.
8. **주인공의 개인적 갈등**: 스승이 남긴 검떼를 물려받은 막내 떼지기. 검떼는 먹이지 않으면 굶주리고, 굶주린 검이 마지막으로 노리는 것은 주인의 화로심장이다. 스승은 왜 사라졌는가.
9. **게임플레이-스토리 연결**: 경험치 = **쇳밥**(적이 흘리는 정련 금속 부스러기)을 검떼가 먹는다 → 레벨업 = **털갈이**. 상점 = 순회 대장장이 **모루할멈**의 간이 화로. 강화 실패 = 담금질 실패. 공명 = 같은 혈통의 짝비행. 사신(시간 초과 압박) = 녹의 순수한 **굶주림**.
10. **비주얼 콘셉트**: 식은 쇠의 남회색 위에 담금질 청색과 잉걸 주황. 녹슨 오렌지 vs 정련된 청강의 대비. 자장 호(弧), 깃털-칼 실루엣, 뜨임색(tempering color) 스펙트럼.
11. **차별점**: "총알 스킨"의 정반대 — 검이 자율 사냥하는 이유가 세계 법칙 그 자체. 사육/목축 판타지와 서바이버 장르의 결합은 선례가 드물다.
12. **장점/위험**: 기존 에셋(짐승형 적 시트, 검 스프라이트)이 그대로 서사에 편입됨. 위험: "새" 비유를 스프라이트가 아니라 움직임·VFX로 전달해야 함(깃털 잔상, 귀소 호 궤적으로 해결).

### 콘셉트 B — 《파음(破音)》 (깨진 종 · 조율)

1~12 요약: 세계는 거대한 종의 잔향 위에 서 있고, 잔향이 닿지 않는 곳의 물질은 형태를 잃어 **소음 덩어리**(=적)가 된다. 검은 하나의 순음을 머금은 음차검(音叉劍) — 조율된 강철은 불협화음 쪽으로 스스로 튕겨나가(자동 발사) 강제로 조율하고(타격) 화음 고리(궤도)로 돌아온다. 플레이어는 심장 박동으로 화음을 유지하는 조율사. 공명 시스템 명칭이 이미 게임에 존재하는 것이 강점. 목표: 균열의 진원까지 종길을 거슬러 오른다.
장점: 공명/필살기와의 개념 일치가 완벽, VFX(파문·파형)가 독보적. 위험: "소음 덩어리" 적은 무정형이라 기존 짐승형 시트와 충돌 — 적 에셋 전면 재제작 필요. 종·파문의 픽셀 가독성도 부담.

### 콘셉트 C — 《빚날》 (대여 무기 · 회수인)

1~12 요약: 이 세계의 무기는 소유할 수 없다 — 모든 검은 은행 대여물이고, 휘두른 값은 이자로 갚는다. 갚지 못한 검은 주인을 삼켜 **연체물**(=적)이 된다. 플레이어는 연체된 검을 회수하는 회수인. 채권이 채무자를 스스로 찾아가듯 검이 날아가고(자동 발사), 회수 할당량(=라운드 목표)을 채운다. 골드·상점·복리 증강("복리 장부"가 이미 존재)과의 결합이 절묘.
장점: 경제 시스템 전체가 서사가 됨, 풍자적 개성. 위험: 장부·인장 같은 시각 언어가 32px 액션에서 안 읽힘, 톤이 액션 쾌감과 어긋날 수 있음, 적 디자인 근거 약함.

### 선정: 콘셉트 A 《쇳깃》

- 검 발사 플레이와의 자연 연결: "매사냥" 하나로 자동 조준·발사·귀환·궤도가 전부 설명됨. 3안 중 유일하게 **회수(귀소)**까지 서사화.
- 한 문장 기억성: "검은 새다. 길들여라."
- 시각 차별성: 녹 vs 청강, 뜨임색, 자장 호 — 고딕/네온 어느 쪽도 아님.
- 구현 가능성: 기존 짐승형 적 시트·검 스프라이트·목표제 라운드가 무수정으로 편입되는 유일한 안.
- 확장성: 혈통(원소) 추가, 야생 검 포획, 지역(폐광·철숲·광재 바다), 검떼 AI 심화.
- 초반 이해도: 매사냥은 설명 없이 직관적.

## 5. 세계관 상세 (쇳깃)

> **사용자 확정 사항 (2026-08-25)**: 콘셉트 A 《쇳깃》 채택. 세계 이름은 영어로 **Lodeland**
> (lode 광맥 + lodestone 자철석 — 자맥이 곧 땅 이름). 신규 조작 '호령'은 **보류**(리스킨만 진행).

| 항목 | 내용 |
|---|---|
| 세계 이름 | **Lodeland** — 자맥(lode)이 흐르는 옛 대정련 지대. 표기 규칙: 표지판·수치 라벨은 영어 대문자(LODE, KILL), 서사·내용은 한국어 |
| 시대 | 대정련이 끝나고 두 세대 뒤. 화로는 식었고 녹은 끓는다 |
| 핵심 법칙 | ① 정련된 금속에는 심(心)이 깃든다 ② 심 있는 금속은 자맥을 타고 난다 ③ 녹은 심을 먹어야 번식한다 |
| 검이 만들어지는 방식 | 자맥 위 화로에서 별쇠·강쇠를 벼리면 심이 깃든다. 두 혈통을 겹쳐 벼리는 것이 **접쇠**(진화) |
| 검을 부리는 조건 | 가슴에 **화로심장**을 단 자만 검떼를 홰에 앉힐 수 있다. 화로심장은 대정련 노동자들의 유산 |
| 비용/위험 | 화로심장은 곧 가장 좋은 먹이 — 검떼가 굶으면 주인을 노리고, 녹은 주인에게 몰려든다 |
| 사회 | 떼지기 조합은 해산됨. 순회 대장장이(모루할멈)들이 자맥길 맥터를 오가며 생존자를 잇는다 |
| 주인공 소속 | 마지막 떼지기 견습. 사라진 스승의 검떼를 물려받음 |
| 대립 | 녹 — 그리고 "녹을 만든 것은 대정련 그 자체"라는 진실 |
| 사람들이 믿는 진실 | 녹은 바깥에서 온 재앙이다 |
| 숨겨진 진실 | 녹은 대정련이 버린 금속의 굶주림이다. 떼지기들의 조상이 만든 것 |
| 게임 시작 전 사건 | 스승이 검떼를 두고 홀로 심맥으로 내려가 돌아오지 않음 |
| 시작 계기 | 스승의 검(놋제비 두 자루)이 갑자기 홰에서 일어나 자맥길 쪽으로 날개를 편다 |
| 진행하며 밝혀지는 것 | 맥터마다 남은 스승의 흔적 → 모루할멈의 증언 → 녹어미의 심장이 스승의 화로심장 |
| 결말의 질문 | 스승은 녹을 멈추려 제 심장을 먹였다. 당신은 검떼를 먹일 것인가, 세상을 먹일 것인가 |
| 후속 갈등 | 야생화된 검떼들, 화로심장을 노리는 인간들, 자맥 고갈 |

**명명 규칙** (의미 없는 영어 금지):
- 검 = [금속·단조어] + [새 이름]. 진화(접쇠) 검 = "-수리" 계열 맹금.
- 적 = "녹-" 접두 또는 고철·부식 순우리말 합성어.
- 등급 = 순우리말 쇠 이름: 무쇠 → 시우쇠 → 강쇠 → 별쇠 → 한쇠.
- 원소 = 혈통: 잉걸(불)·벼락(전기)·삭임(부식)·그믐(자장 소거)·시금(시금석).
- 시스템 용어: 발사→**출격/사냥**, 회수→**귀소**, 궤도→**선회/홰**, 슬롯→**횃대**, 창고→**둥우리**, 강화→**담금질**, 레벨업→**털갈이**, 경험치→**쇳밥**, 골드→**정철**, 진화→**접쇠**, 공명→**짝비행**(용어 유지: 공명).

## 6. 스토리

### A. 현재 빌드 적용분
- **오프닝(런 시작 3줄)**: "스승이 사라진 지 마흔 밤. / 홰에 남은 건 놋제비 두 자리, 그리고 식지 않는 화로심장. / 오늘, 검들이 먼저 날개를 폈다 — 자맥길 쪽으로."
- **초기 목적**: 자맥길의 맥터를 하나씩 정화하며 스승의 흔적을 따라간다.
- **전투 이유**: 녹은 화로심장에 몰려든다. 서 있는 것 자체가 미끼다.
- **중간 사실(10라운드 보스 후)**: 모루할멈 — "녹대 우두머리 뱃속에서 이게 나왔어. 네 스승의 부싯돌이야. 심맥으로 갔구나, 그 양반."
- **보스와 대립하는 이유(60라운드)**: 녹어미의 가슴에서 스승의 화로심장이 뛰고 있다 — 스승은 녹을 늦추려 제 심장을 먹였다.
- **엔딩**: 녹어미를 베면 심장이 멎으며 녹이 잦아든다. 검떼가 일제히 당신의 가슴을 바라본다. "…배고프겠구나. 가자. 다음 맥터로." (승리 화면 문구)
- **남기는 질문**: 검떼를 계속 먹이는 한, 언젠가 당신도 스승과 같은 선택 앞에 선다.
- **전달 수단**: 런 시작 배너 / 라운드 목표 문구 / 보스 등장·처치 연출 문구 / 상점(모루할멈) 한 줄 대사 / 검·적 이름과 툴팁 로어 / 결과 화면 문구 / 첫 30초 튜토리얼 힌트.

### B. 정식 확장용 3막 (요약)
1막: 자맥길 — 겉맥의 맥터들을 되찾으며 스승의 흔적 추적. 2막: 속맥 — 녹이 "침략자가 아니라 버려진 것"임을 알게 됨. 떼지기 조합의 죄. 3막: 심맥 — 녹어미와 스승의 진실, 화로심장을 두고 선택(먹인다/멈춘다/잇는다) 3결말. 후속: 야생 검떼 편.

## 7. 캐릭터

**주인공 — 풀무 (떼지기 견습)**
겉모습: 작달막, 왼가슴의 화로심장 창(窓)에서 잉걸빛이 새어나옴. 두꺼운 가죽 매장갑(홰장갑).
행동: 적을 향해 무기를 들지 않는다 — 손을 들어 무리를 부를 뿐. 목표: 스승을 찾는 것.
감춘 것: 화로심장이 식어가고 있음(부활 메타 업그레이드의 서사 근거 — 심장을 다시 지피는 것).
장점/결함: 검을 아끼는 만큼 제때 풀지 못하고 껴안는 버릇. 대사: "먹자, 얘들아." / "귀소!" / "…미안, 늦게 풀었지."
실루엣 규칙: 사람 + 주변 선회하는 칼날 고리 — 실루엣만으로 식별.
- **홰지기** (기존 광전사): 검을 절대 풀지 않는 늙은 떼지기 — 사슬 비행(궤도 접촉 2.5배). "풀어주면, 돌아오지 않을까 봐."
- **외깃** (기존 검성): 한 자루만 기르는 외매잡이 — 유파가 다르다. "떼는 시끄러워."
- **시금꾼** (기존 도박꾼): 시금 혈통에 전 재산을 건 전직 광석 감정사.
- **모루할멈** (상점): 순회 대장장이. 스승의 옛 동료. 선악 아닌 실리 — "정철만 받아. 심 없는 쇠는 됐고."

## 15. 구현 우선순위

1. 디자인 토큰·theme.ts 재설계 + 글리프 시스템 (모든 화면이 자동 승계)

3. 핵심 HUD 재구성(화로·홰 스트립·목표 패널) + 가짜 UI 제거
4. 검 출격·명중·귀소 피드백 VFX + (승인 시) 호령 스킬
5. 타이틀/캐릭터 선택/일시정지(설정 토글)/결과 화면
6. 스토리 전달 요소(런 인트로·보스 문구·모루할멈 대사·튜토리얼 힌트)
7. 버그 수정: 적 애니메이션, AugmentSystem 타입 오류, 죽은 파일 정리
8. 반응형·입력 점검 + 스모크/플로우 테스트 + 최종 보고
