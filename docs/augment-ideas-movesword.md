# moveSword 증강(Augment) 시스템 적용안

> `augment-research.md`(TFT·LoL 아레나/칼바람·궁수의전설 외 전수 조사)에서 **moveSword에 이식 가능한 것만** 추려 우리 시스템 언어로 번역한 문서.
> 전제가 되는 현재 구조: 60라운드 목표형 / 라운드 간 상점(골드, 스탯 카드, 검 오퍼, 창고, 슬롯) / 검 궤도→발사→귀환 / 물리·마법 + 저항/관통 / 원소 세트(2자루 공명 1.5배, Lv3+ 필살) / 특성 3소켓 / 검 진화 / 슬롯 경제(해방·10강·💎).

---

## 1. 왜 증강인가 — 상점과의 역할 분리

리서치의 핵심 교훈 중 하나: **아레나는 "능력치는 아이템/모루, 규칙 변경은 증강"으로 축을 분리**했다. moveSword도 동일하게 가면 깔끔하다.

- **상점(기존)** = 골드 경제. 스탯 카드, 검 구매/강화, 슬롯 해방 → "수치와 장비"
- **증강(신규)** = 무료 3택1. 규칙 변경, 빌드 정의, 리스크 계약 → "런의 정체성"

상점이 이미 "매 라운드"를 담당하므로, 증강은 **낮은 빈도·높은 임팩트** 슬롯으로 들어가는 게 맞다. TFT(게임당 3회)와 아레나(4회)의 빈도가 근거.

## 2. 제안 시스템 구조

| 항목 | 제안 | 근거 |
|---|---|---|
| 트리거 | **라운드 10 / 25 / 40 / 55 시작 전** 총 4회 (보스 5/15/…/60 직전 라운드와 겹치지 않게 조정 가능) | TFT 2-1/3-2/4-2, 아레나 1·5·8·11. "초반=방향 제시, 중반=커밋, 후반=완성" 커브 |
| 선택 | 3택1, 별도 전체화면 UI (PowerUp 씬 확장 또는 신규 AugmentScene) | 전 게임 공통 표준 |
| 리롤 | 런당 2회 공유 (개별 카드 리롤). 미사용 리롤 → 런 종료 보상 or 상점 리롤로 환급 가능 | TFT 세트9 개별 리롤 + '새로고침 이월' |
| 등급 | **실버/골드/프리즘** 3등급. 슬롯별 확률: 10R 30/60/10 → 25R 30/50/20 → 40R 10/70/20 → 55R 0/60/40 | TFT의 "후반일수록 하한 상승, 마지막 선택은 시시하면 안 됨" |
| 등급 시퀀스 | 런 시작 시 결정 (싱글이므로 공정성 규칙은 불필요 — 대신 시드에 포함해 리플레이 가능하게) | TFT 로비 시퀀스의 싱글 번역 |
| 필터링 | ① 같은 카테고리 2연속 금지 ② 보유 불가 조건 증강 제외(예: 원소 검 0자루면 공명 증강 미제공) ③ 동일 증강 런당 1회 | TFT 경제 3연속 금지, 아레나 킷 필터링 |
| 데이터 | `src/data/augments.js` — {id, name, tier, category, condition(런 상태 필터), apply(scene), desc} | 기존 데이터 주도 구조 유지 |

**등급 철학 (그대로 가져올 것)**: 실버 = 수치, 골드 = 빌드 정의, 프리즘 = **규칙 파괴**. 프리즘을 "골드의 2배 수치"로 만들지 말 것.

### A. 궤도·발사 메커니즘형 (moveSword 고유 — 최우선 차별화 지점)

검 궤도→발사→귀환이라는 고유 사이클의 각 단계에 훅을 거는 계열. 아레나가 "Q/W/E/이동기/CC기" 행동 태그 단위로 증강을 만든 것의 우리식 번역: **궤도 중 / 발사 시 / 비행 중 / 명중 시 / 귀환 시 / 귀환 완료 시**가 우리의 태그다.

| 이름 | 등급 | 효과 | 출처 |
|---|---|---|---|
| 공전 가속 | 실버 | 궤도 회전 속도 +25% | 기본 스탯형 |
| 넓은 궤도 | 실버 | 궤도 반경 +20%, 궤도 접촉 피해 +10% | Archero 원소 서클 |
| 조여오는 칼날 | 실버 | 궤도 반경 -20%, 궤도 회전 속도 +40% (근접 빌드) | Brotato식 트레이드오프 |
| 순환 단축 | 골드 | 발사 쿨다운 -20% | 빵과 버터(슬롯 가속) |
| 저글링 | 골드 | 귀환 완료 시 30% 확률로 그 검 즉시 재발사 | Restart(쿨 초기화) |
| 부메랑 궤적 | 골드 | 발사된 검이 귀환 경로에서도 피해 판정 (귀환 피해 50%) | Ok Boomerang |
| 잔상 궤적 | 프리즘 | 검이 비행한 경로에 1초 뒤 폭발하는 균열 생성 | **대지의 각성(Earthwake)** |

| 도탄 | 골드 | 발사된 검이 적 사이를 1회 튕김 | 리코셰(튕기는 화살) |
| 관통 사출 | 골드 | 발사된 검이 적 1명을 추가 관통 | 관통 화살 |
| 벽 반사 | 실버 | 발사된 검이 화면 경계에서 1회 반사 | Bouncy Wall |
| 귀환 인력 | 실버 | 귀환하는 검이 경로 위 경험치/골드를 끌어옴 | Attractorb |
| 칼끝 폭풍 | 골드 | 검이 3회 연속 명중 시 소형 회오리 생성 | 온-힛 프록 번역 |
| 정지 궤도 | 프리즘 | 검 1자루를 지정 위치에 고정 터렛으로 전환 (수동 배치) | 그림자 분신 / Lightning Rod |
| 위성 낙하 | 프리즘 | 발사 대신 검이 하늘에서 목표 지점에 낙하 폭격 (발사 로직 교체) | **궤도형 레이저** / 원소 메테오 |

### B. 검/장비 제공형 (모루 = 선택권 지급)

리서치 교훈: 완성품 지급(운) < **모루(선택권)** < 판도라(재배열권)로 통제 수준을 나눠라.

| 이름 | 등급 | 효과 | 출처 |
|---|---|---|---|
| 검 꾸러미 | 실버 | 무작위 2단계 검 1자루 (창고 입고) | Item Grab Bag |
| 대장간의 부름 | 골드 | **검 모루**: 현재 단계+1 검 4자루 중 1택 | **휴대용 대장간** |
| 명검 대장간 | 프리즘 | 희귀 검(저항 관통/초희귀 옵션 보장) 4택1 | Portable Forge 상위 |
| 살아있는 대장간 | 프리즘 | 즉시 + 이후 10라운드마다 검 모루 제공 | Living Forge |
| 판도라의 창고 | 골드 | 매 라운드 시작 시 **창고(reserve)의 검**이 같은 단계 무작위 검으로 재배열 (장착 검은 불변) | **판도라의 아이템** — 창고 시스템과 정확히 맞물림 |
| 강화 전수 | 골드 | 다음에 구매하는 검이 창고 최고 레벨 검의 레벨을 상속 | 별의 탄생(즉시 2성) |
| 쌍둥이 검 | 골드 | 장착 검 1자루 선택 → 2라운드 뒤 복사본 창고 입고 | 복제(Replication) |
| 유물 소켓 | 프리즘 | 무작위 특성 3개가 박힌 검 1자루 지급 (소켓 3칸 만석) | **방랑 조련사** |

### C. 원소/세트형 (기존 공명·필살 시스템의 레버)

TFT 문장(+1 특성)의 번역: 우리의 "특성 단계"는 원소 세트다. **원소 부여 = 문장**.

| 이름 | 등급 | 효과 | 출처 |
|---|---|---|---|
| 화염의 문장 | 골드 | 검 1자루 선택 → 화염 속성 부여 (기존 속성 대체) | **○○ 문장(Emblem)** |
| 뇌전의 문장 | 골드 | 검 1자루에 번개 속성 부여 | 문장 |
| 공허의 문장 | 골드 | 검 1자루에 특이점 속성 부여 | 문장 |
| 원소의 왕관 | 프리즘 | 속성 부여 + 그 원소 검 1자루 + 공명 효과 +25% | **왕관(Crown)** |
| 공명 증폭 | 골드 | 원소 공명 배율 1.5 → 1.75배 | 특성 강화형 |
| 삼중 공명 | 프리즘 | 같은 원소 3자루 장착 시 공명 2.5배 + 필살 쿨다운 -30% | 상위 시너지 단계 신설 |
| 무색의 힘 | 실버~프리즘 | **무속성 검**만 피해 +40%/공속 +30% (등급별 스케일) | **남다른 육성(Built Different)** — 역발상 그대로 |

| 필살 연쇄 | 프리즘 | 필살기(노바/낙뢰/특이점) 발동 시 30% 확률로 즉시 1회 추가 발동 | 궁극기 대변혁 |

| 이중 속성 | 프리즘 | 검 1자루가 원소 2개를 동시 보유 (양쪽 공명에 카운트) | 전능의 영혼 |

### J. 검 전용 증강 (영웅 증강의 번역 — 신중히)

TFT의 교훈: 유닛 단위 증강은 다양성 폭발 but **밸런스 표면적 = 검 종류 × 2**. 세트 13처럼 "런당 1회, 별도 슬롯"으로 축소 도입이 정답.

- **구조 제안**: 40라운드 증강을 "검 각성"으로 대체 가능 — 장착 검 중 1자루 선택, 그 검 전용 각성 2종 중 1택 (골드 무한 리롤 = 이상 현상 방식).
- 예시:
  - 기본 검(1단계)용 "고물의 반란": 이 검 피해 +200%, 단계가 낮을수록 추가 보너스 — *남다른 육성 문법*
  - 화염검용 "겁화": 필살 노바가 장판을 남김
  - 관통검용 "꿰뚫는 자": 관통 수 무제한, 피해 -30%
  - 진화 검용 "완전체": 진화 조건 특성 소켓 1칸 반환
- 캐리형/서포트형 이원화도 가능: "이 검을 강하게" vs "이 검이 다른 검을 돕게" (귀환 시 다른 검 쿨 감소 등).

## 4. 도입 로드맵 제안

**Phase 1 — 뼈대 (작게 시작)**
- AugmentScene(3택1 UI, 카드 연출) + `data/augments.js` + 라운드 10/25/40/55 트리거
- 실버/골드만, 카테고리 D(스탯)·E(온-힛)·F(경제)·G(생존)에서 20~25종
- 리롤 2회, 카테고리 2연속 금지 필터

**Phase 2 — 정체성**
- 프리즘 등급 + 등급 시퀀스/확률표
- A(궤도·발사) 전체 — **차별화의 핵심이므로 여기에 물량 투자**
- C(원소/세트) — 기존 공명·필살 시스템과 연결
- H(리스크) 대표 5종: 저주받은 왕관, 잔혹한 계약, 황금 알, 거인의 검, 아홉 개의 목숨

**Phase 3 — 깊이**
- J(검 각성, 40R 특수 슬롯) / K(메타 증강) / L(수집·듀오·진화 촉매)
- 무피해 클리어 → 프리즘 보장 같은 플레이 연동 보상

**밸런스/구현 주의 (리서치에서 직접 도출)**
1. 프리즘은 수치 2배가 아니라 규칙 변경 — 구현 시 apply()가 시스템 훅을 건드리는 구조여야 함 (recalc 전면 재계산 필수, 기존 "검 배치 변경 후 전체 recalc" 함정 그대로 적용됨).
2. 필터링이 UX의 절반: 원소 검 없는 런에 공명 증강이 나오면 그 슬롯은 "꽝"이다. condition 필드를 처음부터 설계할 것.
3. 가독성: 자동 시전형은 빈도 낮게·임팩트 크게, 상시 파티클 오라는 피할 것 (아수라장 교훈 — 우리도 검 여러 자루가 이미 화면을 채운다).
4. 온-힛 키워드(화상/감전/처형/처치폭발)는 처음부터 **StatusSystem으로 일원화**해 두면 증강·검 특성·필살기가 같은 키워드를 공유하며 곱연산된다.
5. 60라운드 목표형 구조상 증강 타이밍이 보스(x5/x0) 직전이면 "보스 대비 픽"이라는 맥락이 생겨 선택이 더 재밌어진다 — 트리거 라운드를 보스 -1로 두는 안 검토.
