# 쇳깃 — 리디자인 최종 보고서

> 2026-08-25. `docs/redesign-proposal.md`(제안) 의 실제 구현 결과.

## 1. 확정된 게임 제목과 한 문장 소개

**《쇳깃》 (Iron Plume)** — 검은 길들인 맹금이다. 마지막 떼지기가 되어 검떼를 몰아,
Lodeland의 자맥길을 삼키는 녹(綠)을 사냥한다.

## 2. 세계관 및 핵심 스토리

- **세계**: Lodeland — 자맥(lode, 자기 광맥)이 흐르는 옛 대정련 지대. 정련된 금속에는 심(心)이 깃들어 자맥을 타고 난다. 화로심장을 단 자만 검떼를 홰에 앉힐 수 있다.
- **적의 규칙**: 녹은 대정련이 버린 금속의 굶주림. 심을 먹어야 번식하므로, 세상에 남은 가장 큰 심 덩어리(=화로심장을 단 플레이어와 그의 검떼)에게 무리 지어 몰려든다 — 장르의 "무한 쇄도"가 세계 법칙에서 나온다.
- **발사의 근거**: 매사냥. 검떼는 사정거리에 든 먹잇감을 스스로 덮치고(자동 조준·발사) 홰(궤도)로 귀소한다. 떼지기는 조준하지 않는다 — 무리를 고르고(장착), 먹이고(쇳밥), 벼리고(담금질), 몰 뿐(이동).
- **핵심 스토리(현재 빌드)**: 스승이 사라진 지 마흔 밤, 검들이 먼저 자맥길로 날개를 편다(런 인트로 3줄) → 맥터를 정화하며 모루할멈의 증언으로 진실 조각이 밝혀진다(상점 이정표 대사 12종) → 심맥의 녹어미 가슴에는 스승의 화로심장이 뛰고 있다(60맥 연출 문구) → 벤 뒤, 굶주린 검떼가 당신의 가슴을 바라본다(승리 문구).
- **전달 수단**: 런 인트로, 튜토리얼 힌트(신규 플레이어), 라운드 목표 문구, 배너, 모루할멈 대사, 검·적 이름/로어 툴팁, 결과 화면 문구 — 별도 오프닝 영상·설명문 없음.

## 3. 주요 캐릭터와 세력

| 이름 | 역할 |
|---|---|
| **풀무** (기본) | 막내 떼지기. 스승의 검떼를 물려받음. 균형형 |
| **홰지기** | 검을 절대 풀지 않는 늙은 떼지기 — 사슬 비행(선회 접촉 2.5배, 출격 없음) |
| **외깃** | 한 자루만 기르는 외매잡이 유파 (검 1자루·피해 2.5배) |
| **시금꾼** | 시금 혈통에 전 재산을 건 전직 감정사 (길조·정철 특화) |
| **모루할멈** | 순회 대장장이(상점). 스승의 옛 동료 — 서사 전달자 |
| **녹** | 적 세력. 침략자가 아니라 "버려진 것들의 굶주림" |
