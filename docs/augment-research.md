# 1부. TFT (롤토체스) 증강

## 1.1 시스템 구조

### 기본 제공 방식
- **도입**: 세트 6 "기계와 장치"의 '마법공학 증강체'로 첫 도입 → 반응이 좋아 세트 7부터 영구 핵심 시스템화.
- **제공 스테이지**: 게임당 3회 — **2-1, 3-2, 4-2** (하이퍼롤은 3-1, 5-2, 7-2). 라운드 시작 시 전투 대신 선택 UI.
- **선택**: 매번 **3택1**. 제한 시간 첫 증강 43초, 이후 58초. 미선택 시 자동 선택.
- **리롤**: 슬롯당 무료 1회. 초기엔 없었고 → 3개 전체 리롤 → 세트 9부터 **개별 증강 1개만 리롤 가능**하게 개선.

### 등급과 확률
- 3등급: **실버 < 골드 < 프리즘**. 같은 콘셉트가 I/II/III 버전으로 등급 분할되는 경우 다수.
- **로비 공통 시퀀스**: 등급 조합(예: 골드→실버→프리즘)은 게임 시작 시 결정, **8명 전원 동일**. "운은 공평하게, 선택은 개인적으로".
- 슬롯별 확률 (세트 16): 2-1 실버28/골드62/프리즘10 → 3-2 35/45/20 → **4-2 6/74/20** — 후반 슬롯일수록 하한을 끌어올려 마지막 선택이 시시하지 않게.
- 프리즘 3연속("프리즘 잔치")은 약 1~2% 희귀 이벤트.
- **내용 제약**: 경제 증강 3연속 금지, 진행 상황과 모순되는 증강 필터링.
- **확률 조작**: '증강된 힘'(다음 증강 등급 +1), '대출 선지급'(20골드 받고 다음 등급 -1) — 확률표 자체를 화폐로.

### 세트별 변형
| 세트 | 변형 | 내용 |
|---|---|---|
| 6~6.5 | 마법공학 증강체 | 원형. 리롤 없음 |
| 8~8.5 | **영웅 증강** | 3회 중 1회가 챔피언 전용 증강. 챔피언마다 캐리형/서포트형 2종 |
| 9~9.5 | 전설 + 차원문 | 사전 선택한 '전설'의 테마 증강 보장 제공 → 메타 수렴으로 한 세트 만에 폐지 |
| 11 | 조우(Encounters) | 무작위 이벤트가 증강 타이밍·등급 변조 |
| 12 | 참(Charms) | 매 라운드 골드로 사는 1회용 미니 증강 |
| 13 | 이상 현상(Anomaly) | 4-6에 유닛 1명에게 부여하는 유닛 단위 증강, 골드 무한 리롤 |
| 14 | 해킹 | 증강 선택지 4개로 확장 등 규칙 변조 |

## 1.4 TFT 디자인 노트
- **등급 = 규칙 개입의 깊이**: 실버=양념, 골드=기준선, 프리즘=게임 변형. 프리즘을 "골드의 2배 수치"로 만들지 않은 것이 핵심.
- **타이밍 설계**: 2-1(정보 부족기)=경제·범용이 강세, 3-2(분기점)=커밋형 선택, 4-2(완성기)=실버 6%로 사실상 봉인 — 종반 선택이 하찮으면 안 된다는 원칙.
- **아키타입 발생기**: 증강 하나가 플레이스타일 하나를 정의(남다른 육성=무특성 덱, 황금 티켓=리롤 덱, 계산된 손실=연패 오픈).
- **제공 알고리즘도 디자인**: 카테고리 상한, 문맥 필터로 "3개 전부 꽝" 방지.
- **실험의 교훈**: 유닛 단위 증강(영웅 증강)은 다양성 폭발 but 밸런스 표면적 폭증 → "게임당 1회, 별도 슬롯"으로 축소가 정답. 운을 사전 선택으로 바꾸면(전설 시스템) 메타가 굳는다.

## 2.1 시스템 구조

### 아레나 (2v2v2v2, 8팀 16인)
- 상점 페이즈 ↔ 전투 페이즈 반복. 팀 체력 100, 패배 시 감소(후반일수록 크게), 0이면 탈락.
- 증강 선택 **총 4회** (라운드 1·5·8·11), 3택1, 리롤 기본 2회(상점 리롤과 풀 공유, 명성 5레벨 시 +1). 리롤해도 등급 유지.
- 등급 실버/골드/프리즘. **같은 선택 라운드에는 16명 전원 동일 등급**.
- 규칙: 동일 증강 게임당 최대 4회 등장, **챔피언 킷 기반 필터링**(돌진기 없는 챔피언에게 이동기 증강 미제공), 기 선택 증강·아이템과 중복 배제.

- 증강과 별개로 **능력치 모루/전설 모루/프리즘 아이템 모루/주스** — "능력치는 아이템·모루, 규칙 변경은 증강"으로 역할 분리.
- 연혁: 2023.7 소울 파이터 이벤트 첫 출시(약 60종) → 지속 확장, 현재 누적 200종+.

### 칼바람 아수라장 (ARAM: Mayhem = "증강 칼바람")

## 2.4 아레나/아수라장 디자인 노트
- **비대칭 환경의 범용화 해법**: ① 적응형 스탯·AD↔AP 변환 ② **제공 단계 필터링** — "모두에게 맞는 증강"이 아니라 "맞는 증강만 보여주기" ③ **행동 태그 단위 추상화** (Q/W/E 슬롯, 이동기, CC기, 회복기 단위로 강화) ④ 킷 무관 자동 무기(부메랑, 그랩, 미사일) ⑤ 기존 챔피언 스킬 이식(borrowing)으로 개발비 절감 + 즉시 이해되는 판타지.
- **등급 판타지**: 실버=스탯 미세조정/접착제, 골드=빌드 정의(build-around), 프리즘=규칙 파괴(변신·역할 전환·무한 성장·새 주문). 전원 동일 등급 규칙으로 프리즘 라운드는 "모두가 동시에 미쳐 돌아가는 축제".
- **시너지 유도**: 키워드 패밀리(치명타/화상/온-힛/회복/CC)끼리 곱연산 → 증강 4개가 '덱'이 됨. 빵 시리즈 같은 명시적 세트는 "다음 선택 화면에 대한 기대"를 만듦. 퀘스트형은 라운드 중 단기 목표 부여.
- **아이템·증강 이원화**: 능력치는 모루, 메커니즘은 증강 — 선택 축이 겹치지 않게.
- **아수라장의 교훈**: 인원 많은 난전에서는 상시 오라형 제외, 자동 시전형은 "빈도 낮게, 임팩트 크게" — **가독성도 밸런스의 일부**.

## 3.1 궁수의전설 (Archero / Archero 2)

### 드래프트 구조
- **레벨업**: 랜덤 능력 **3택1**. 보유 능력의 상위 단계(멀티샷→멀티샷+)가 섞여 나옴.
- **천사방**: 특정 방에서 "체력 회복 vs 하급 천사 능력" **2택1**. 천사 풀: HP 강화, 강한 심장, 공격력/공속/치명(소). 통설: 체력이 위험하지 않으면 능력.
- **악마의 계약**: **보스를 무피해로 잡으면** 등장. **최대 HP 약 20% 영구 지불**하고 능력 구매. 목숨+1, 벽 통과 등 계약 전용 능력 포함. → 획득 경로 자체가 플레이 목표(무피해)와 연결된 대표 사례.
- **Archero 2**: 스킬 등급(Fine/Rare/Epic/Legendary) 도입. x5 스테이지 발키리(고등급), x9 스테이지 천사(회복·서포트), 무피해 보스 후 악마(HP 대가 공격 스킬).

# 4부. 종합 디자인 교훈

1. **3택1이 표준 리듬.** 인지 부하와 의미 있는 선택의 균형점. 선택지 수 확장은 스탯(행운)이나 능력(영리함=XP 가속)으로 "드래프트에 투자하는 빌드"까지 허용.
2. **레시피형 진화가 밋밋한 선택지에 2차 가치를 부여.** VS 패시브, 탕탕 보조 스킬, Hades 듀오, 빵 샌드위치 — 단독으론 평범한 픽이 "조합 열쇠"가 되어 드래프트가 **여러 픽에 걸친 계획**이 됨.
3. **직교 축의 곱연산.** (투사체 수 × 거동 × 원소), (슬롯 × 신 × 등급) — 축을 분리하면 적은 능력 수로 방대한 빌드 공간.
4. **트레이드오프는 '빌드 상대적'일 때 최고.** 절대 손해가 아니라 **내 빌드가 버린 축을 지불**하게 하면 선택이 퍼즐이 된다 (Brotato -사거리, 악마의 계약 -최대HP).
5. **획득 경로마다 다른 통화·리스크.** 레벨업(무료) / 천사방(회복과 교환) / 악마(HP 지불) / 상점(골드) / 무피해 보스(플레이 실력) — 드래프트 획득 자체를 게임플레이 목표와 연결.
6. **등급은 같은 능력의 세로축.** 새 능력을 늘리지 않고 도박성 부여 + "등급 강화 메타 픽"(증강된 힘, 골든 리롤, Exclusive Access)이라는 상위 전략층.
7. **빌드 정체성은 편식을 보상하는 데서.** 듀오·진화 레시피·원소 세트 모두 "한 우물"에 비선형 보상 → 매 런이 "이번엔 ○○ 빌드"로 요약되는 것이 리텐션의 핵심.
8. **제공 알고리즘도 디자인의 일부.** 문맥 필터링(부적합 제외), 카테고리 연속 제한, 동일 증강 등장 상한, 전원 동일 등급(멀티) — "3개 전부 꽝"과 "격차 불만"을 시스템으로 방지.
9. **등급이 오를수록 수치가 아니라 규칙 개입 깊이가 커진다.** 프리즘 = 변신, 역할 전환, 자원 교체, 무한 성장 — "이 게임에서만 가능한 이야기".
10. **가독성도 밸런스.** 난전 환경에서는 상시 오라형 제외, 자동 시전은 빈도↓ 임팩트↑ (아수라장의 교훈).
