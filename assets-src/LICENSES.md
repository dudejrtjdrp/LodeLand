# 에셋 라이선스 장부

외부 에셋을 하나라도 받으면 **받은 즉시** 아래 형식으로 항목을 추가한다.
크레딧이 필요한 라이선스(CC-BY 등)를 쓰면 게임 내 크레딧 화면에도 같은 정보를 노출해야 한다.

```markdown
## <카테고리>/<팩이름>
- 출처: <URL>
- 작성자:
- 라이선스:
- 받은 날짜: YYYY-MM-DD
- 원본 위치: assets-src/...
- 사용처: <게임 내 텍스처 키 / public 경로>
- 가공: <스크립트 이름과 처리 내용>
```
