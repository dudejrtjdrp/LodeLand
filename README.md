# moveSword

Phaser 3 starter structure for a Vampire Survivors-like game.

## Structure

- `index.html`: minimal entry point, no inline game config
- `src/main.js`: bootstraps the Phaser game
- `src/gameConfig.js`: shared game configuration
- `src/scenes/GameScene.js`: player movement, camera follow, scrolling background
- `public/assets/player.png`: player sprite loaded with the `player` key
- `public/assets/bg.png`: background image loaded with the `bg` key

## Run

```bash
npm install
npm run dev
```
