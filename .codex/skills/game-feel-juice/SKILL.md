# 게임필 / Juice 튜닝

타격감은 그림이 아니라 **타이밍의 문제**다. 이펙트를 아무리 예쁘게 만들어도 아래 레이어가 없으면 밋밋하고, 반대로 아래가 갖춰지면 도형만으로도 시원하다.

## 1. 한 번의 타격에 겹치는 레이어

강한 타격 하나는 아래가 **동시에** 일어난다. 하나라도 빠지면 약해지고, 다 넣으면 과하다 — 강도별로 골라 쓴다.

| 레이어 | 약공격 | 강공격 | 필살기/보스 |
|---|---|---|---|
| 히트스톱 | 0~20ms | 40~60ms | 80~120ms |
| 화면 흔들림 | 없음 | 100ms / 0.003 | 200~250ms / 0.006 |
| 임팩트 프레임 홀드 | 1프레임 | 2프레임 | 2~3프레임 |
| 파티클 | 3~5개 | 8~12개 | 14~20개 |
| 화면 색 펄스 | 없음 | 없음 | 300~400ms 비네트 |
| 데미지 숫자 | 작게 | 크게 | 크게 + 색 |
| 사운드 | 짧은 틱 | 저역 포함 | 저역 + 리버브 |

## 2. 히트스톱

- 타격이 "닿았다"고 알리는 가장 값싼 수단. **시간 스케일을 낮추는 방식**을 쓰고, 물리 엔진을 `pause` 하지 않는다 (재개 시 레이스로 프리즈 버그가 난다).
- 처치 확정타(destructive confirm)는 60~80ms가 체감이 좋다.
- 히트스톱 중에는 입력을 버퍼링해야 한다. 안 그러면 "조작이 씹힌다"고 느낀다.
- 다중 히트가 겹치면 **합산하지 말고 최댓값으로 덮어쓴다**. 합산하면 적이 많을 때 게임이 슬로우모션이 된다.
- 반드시 해제 보장을 둔다 (타임아웃, 씬 전환 시 강제 복구). 미해제 히트스톱은 프리즈로 보인다.

## 3. 화면 흔들림

- **짧게, 감쇠 곡선과 함께.** 50~300ms. 지속이 길면 멀미가 난다.
- **방향성**을 준다: 타격 벡터 방향으로 흔들면 훨씬 정확하게 읽힌다.
- 진폭은 지수 감쇠. 선형 감쇠는 뚝 끊기는 느낌이 난다.
- 동시 다발 시 **최댓값 유지**, 누적 금지.
- 설정에서 끌 수 있어야 한다 (접근성). 끈 상태에서도 게임이 읽히도록 다른 레이어로 보완한다.

## 4. 임팩트 프레임과 애니메이션 타이밍

- 앤티시페이션(준비 동작) 없이 시작하는 공격은 무게가 없다. 큰 공격일수록 준비를 길게(최대 400ms).
- 최대 신장 프레임을 **홀드**한다 (150~300ms). 등속 재생하면 임팩트가 사라진다.
- 회수(recovery)는 2~3프레임으로 짧게.
- 스미어 프레임(잔상으로 길게 늘인 1프레임)은 빠른 휘두르기의 속도를 파는 픽셀아트의 필살기다.

## 5. 텔레그래프 (보스/위험 지대)

- 예고 시간은 최소 **0.6초**, 큰 기술은 1.2~1.5초. 그보다 짧으면 반응이 아니라 암기가 된다.
- 예고는 **진행도가 보여야** 한다: 채워지는 원, 좁혀지는 링, 알파가 올라가는 띠 — 남은 시간을 읽을 수 있게.
- 안전 지대를 다른 색(보통 초록)으로 명시한다.
- 발동 순간에 예고와 다른 **밝은 프레임 1장**을 넣어 "지금이다"를 알린다.
- 예고 색과 피격 색을 절대 같게 하지 않는다.

## 6. 서바이버류 특유의 주의

- 적이 수백 마리다. **개별 타격 연출은 반드시 레이트 리밋**을 건다 (같은 종류 40~90ms). 안 그러면 30라운드에서 렉으로 죽는다.
- 화면이 가득 찰수록 **플레이어 캐릭터의 가독성**이 최우선이다. 이펙트 알파를 낮추고 뎁스를 캐릭터 아래로 내리는 편이 낫다.
- 큰 이펙트일수록 짧게. 화면을 덮는 연출이 0.5초를 넘으면 정보가 사라진다.
- 처치 연출을 등급별로 분리한다: 잡몹은 점 하나, 정예는 파편, 보스는 다단 연출.

## 7. 진단 순서 ("밋밋한데 왜인지 모르겠다")

1. 히트스톱이 있는가 → 없으면 40ms부터 넣어본다
2. 임팩트 프레임을 홀드하는가 → 등속 재생이면 홀드 추가
3. 사운드가 타격 프레임과 같은 프레임에 나는가 → 1프레임만 늦어도 어긋나 들린다
4. 파티클이 타격 방향으로 튀는가 → 사방으로 균등하면 방향감이 없다
5. 적이 반응하는가 → 흰색 플래시 + 넉백 + 경직 중 최소 2개
6. 그다음에 이펙트 그림을 의심한다
