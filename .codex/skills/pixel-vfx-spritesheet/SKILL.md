# 픽셀 VFX 스프라이트시트 제작

절차적으로(도형+트윈) 그린 이펙트를 스프라이트 애니메이션으로 바꾸거나, 새 이펙트 시트를 만들 때의 규격서다.

## 1. 먼저 이펙트의 "문법"을 정한다

모든 단발 이펙트는 **팽창 → 분산 → 소멸(expansion → dispersion → fade)** 3막이다. 프레임을 배분하기 전에 이 이펙트가 어느 유형인지 확정한다.

| 유형 | 예 | 프레임 | 재생 | 루프 | 앵커 |
|---|---|---|---|---|---|
| 임팩트 (impact) | 타격 스파크, 처형 | 5~6 | 24~30fps | 없음 | 중앙 |
| 노바 (nova) | 화염/서리 폭발 | 9~12 | 20~24fps | 없음 | 중앙 |
| 방향기 (directional) | 검기, 원뿔 베기 | 7~8 | 24fps | 없음 | **왼쪽 중앙** |
| 낙하/기둥 (column) | 낙뢰, 광선 | 6~8 | 30fps | 없음 | 하단 중앙 |
| 지속 장판 (field loop) | 불바다, 독구름, 룬 | 8 | 10~12fps | **무한** | 중앙 |
| 부착 오버레이 (attach) | 빙결, 화상, 출혈 | 형성 6 + 루프 4 | 12fps | 루프만 | 발밑 기준 |

핵심 규칙 — **지속 효과를 단발 이펙트의 반복 스탬프로 만들지 않는다.** 90ms마다 도형을 다시 찍는 구현은 CPU를 태우면서 보기도 나쁘다. 루프 시트 1장이 정답이고, 성능도 오히려 좋아진다.

## 2. 프레임 타이밍 (게임필과 직결)

- 임팩트 프레임(가장 크고 밝은 프레임)은 **1~2프레임만** 존재하고, 그 앞뒤가 전부 준비/여운이다.
- 노바형 배분: 팽창 2프레임(빠름) → 최대 1~2프레임(**여기서 홀드**) → 분산 3~4 → 페이드 2~3.
- 방향기: 앤티시페이션 1 → 최대 신장 1~2 → 회수 3.
- 프레임레이트를 24fps 위로 올릴수록 "날카롭게", 12fps로 내릴수록 "묵직하게" 읽힌다. 지속 루프는 12fps 이하로 두어야 눈이 피로하지 않다.
- 첫 프레임은 절대 최대 크기로 시작하지 않는다. 1프레임이라도 작게 시작해야 "터졌다"고 읽힌다.

## 3. 픽셀 규율

- **논리 픽셀 크기를 고정한다.** 프레임이 256px이고 게임의 픽셀 단위가 4px이면, 모든 형태는 4의 배수 격자에 스냅한다. 안티에일리어싱된 부드러운 원은 픽셀아트 톤을 즉시 깨뜨린다.
- **알파는 이진(binary)으로.** 0 또는 255. 반투명 가장자리는 NEAREST 필터에서 지저분해진다. 반투명이 필요하면 스프라이트 자체의 `alpha`/`ADD` 블렌드로 처리한다.
- **색은 3~4단계까지.** 코어(가장 밝음, 거의 흰색) → 본색 → 그림자색 → 외곽. 원소별 램프를 미리 정하고 모든 시트가 그 램프만 쓰게 한다.
- **코어는 흰색으로 뽑고 런타임 틴트로 원소를 바꾼다.** 회색조/백색 위주로 만든 시트 1장이면 8원소를 `setTint`로 커버한다 — 시트 수가 1/8로 줄어든다. 다만 틴트는 곱연산이라 베이스가 어두우면 안 먹으니 베이스를 밝게 뽑아야 한다.
- 발광 이펙트는 `BlendModes.ADD` 를 전제로 그린다. ADD 에서는 검정이 투명이므로 어두운 외곽선을 넣지 않는다.

## 4. 회전 대응 규격

방향성 이펙트(검기·돌진·광선·원뿔)는 런타임에서 `setRotation(angle)` 으로 조준을 맞춘다. 따라서:

- **+X(오른쪽)를 향하도록 그린다.** 위나 아래를 향해 그리면 코드에서 오프셋 보정이 붙고 결국 어긋난다.
- 회전 중심을 원점으로 쓸 수 있게 `setOrigin(0, 0.5)` 전제로 왼쪽 중앙에 시전자 위치를 둔다.
- 프레임 캔버스는 최대 신장 프레임 기준으로 잡고, 모든 프레임이 **같은 캔버스 크기**를 유지한다(프레임마다 bbox 크롭 금지 — 애니메이션이 튄다).

## 5. Python(PIL) 생성 파이프라인

시트를 자작할 때의 표준 골격. 프로젝트에 이미 `scripts/generate-*.py` 관례가 있으면 그것을 따른다.

```python
from PIL import Image, ImageDraw
import math

FRAME, FRAMES, COLS = 256, 10, 5
PX = 4  # 논리 픽셀

def snap(v):            # 격자 스냅
    return round(v / PX) * PX

def frame(i):
    t = i / (FRAMES - 1)
    img = Image.new('RGBA', (FRAME, FRAME), (0, 0, 0, 0))
    d = ImageDraw.Draw(img)
    c = FRAME // 2
    # 팽창(ease-out) 후 페이드
    r = snap(FRAME * 0.46 * (1 - (1 - t) ** 2))
    a = 255 if t < 0.35 else int(255 * (1 - (t - 0.35) / 0.65))
    for rr, col in ((r, (255, 120, 40, a)), (r * 0.62, (255, 220, 150, a))):
        d.ellipse([c - rr, c - rr, c + rr, c + rr], outline=col, width=PX * 2)
    return img

sheet = Image.new('RGBA', (FRAME * COLS, FRAME * math.ceil(FRAMES / COLS)), (0, 0, 0, 0))
for i in range(FRAMES):
    sheet.paste(frame(i), ((i % COLS) * FRAME, (i // COLS) * FRAME))

# 저장 직전 반드시 알파 이진화 — 이걸 빼먹으면 NEAREST 에서 가장자리가 지저분해진다
px = sheet.load()
for y in range(sheet.height):
    for x in range(sheet.width):
        r, g, b, a = px[x, y]
        px[x, y] = (r, g, b, 255 if a > 96 else 0)
sheet.save('out.png')
```

### 함정 (실제로 당한 것들)
- **반투명 알파 함정**: PIL로 반투명을 겹쳐 그리면 알파가 누적되어 의도한 톤이 안 나온다. 레이어를 따로 그려 `alpha_composite` 하거나 위처럼 마지막에 이진화한다.
- **`paste` 는 알파를 덮어쓴다.** 겹쳐 합성할 때는 `Image.alpha_composite` 또는 `paste(img, box, img)` (마스크 인자) 를 쓴다.
- 그리드 마지막 줄의 빈 칸은 완전 투명이어야 한다. 엔진이 `end: FRAMES-1` 로 잘라 읽지만, 빈 칸이 불투명하면 아틀라스 패커가 잘못 트림한다.

## 6. 매니페스트를 같이 생성한다

시트를 만들면 **코드에서 프레임 수를 손으로 적지 않도록** 매니페스트를 자동 생성한다. 프레임 수 불일치는 가장 흔한 런타임 버그다.

```ts
// AUTO-GENERATED by scripts/generate-fx-sheets.py — 손으로 고치지 말 것
export interface FxSheetSpec { frameSize: number; frames: number; fps: number; loop: boolean }
export const FX_SHEETS: Record<string, FxSheetSpec> = {
  'fx-nova-fire': { frameSize: 256, frames: 10, fps: 22, loop: false },
  'fx-field-fire': { frameSize: 300, frames: 8, fps: 11, loop: true },
};
```

## 7. 체크리스트

- [ ] 유형·프레임 수·fps·루프 여부를 표에서 골랐다
- [ ] 첫 프레임이 최대 크기가 아니다 / 임팩트 프레임이 1~2개뿐이다
- [ ] 모든 프레임이 동일한 캔버스 크기다
- [ ] 방향성 이펙트가 +X 를 향한다
- [ ] 알파가 이진이다
- [ ] 팔레트가 4단계 이하이고 원소 램프를 따른다
- [ ] 매니페스트를 자동 생성했다
- [ ] 인게임 스크린샷으로 실제 크기를 확인했다 (에디터에서 예뻐도 인게임에서 너무 크거나 안 보이는 경우가 대부분)
