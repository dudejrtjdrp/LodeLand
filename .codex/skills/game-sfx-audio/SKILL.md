# 게임 사운드 에셋

## 1. 타격음은 레이어다

강한 타격음 하나 = **트랜지언트 + 바디 + 테일** 세 겹.

| 겹 | 길이 | 역할 |
|---|---|---|
| 트랜지언트 | 5~20ms | "닿았다" — 클릭/틱, 고역 |
| 바디 | 50~150ms | 무게 — 중저역, 재질감 |
| 테일 | 100~400ms | 공간 — 잔향, 필살기에만 |

약공격은 트랜지언트만, 강공격은 +바디, 필살기는 셋 다. 전부에 테일을 붙이면 소리가 뭉갠다.

## 2. 이펙트와 동기화

- 사운드는 **이펙트의 임팩트 프레임과 같은 프레임**에 나야 한다. 1프레임(16ms)만 늦어도 어긋나 들린다.
- 히트스톱이 걸리면 사운드는 **멈추지 않는다** (오디오는 실시간). 히트스톱 길이만큼 사운드 어택을 앞당기면 더 맞아 들린다.
- 텔레그래프에는 예고음을 따로 준다. 발동음과 구분되어야 한다.

## 3. 동시 재생 제한 (서바이버류 필수)

적이 수백이면 타격음이 수백 번 난다. 그대로 두면 귀가 아프고 오디오 채널이 터진다.

- **같은 사운드는 프레임당 1회, 최소 간격 40~60ms**로 제한한다
- 동시 재생 상한(예: 종류당 4개)을 두고 초과하면 가장 오래된 것을 끊는다
- 여러 타격이 겹치면 볼륨을 합산하지 말고 **미세한 피치 랜덤(±5%)** 을 준다. 같은 소리가 겹치면 기계음처럼 들린다
- 처치음은 잡몹/정예/보스로 분리하고, 잡몹 처치음은 아주 작게

## 4. 볼륨 예산

전체 100 기준 대략: BGM 30 / 타격 25 / 스킬 20 / UI 10 / 환경 10 / 보스 콜아웃 피크 100. 모든 것이 크면 아무것도 안 크다.

## 5. 조달

### 무료 음원
- **freesound.org** — 파일마다 라이선스가 다르다. **CC0 필터 필수**
- **OpenGameArt 오디오 섹션** — CC0 필터: https://opengameart.org/content/cc0-resources
- **Kenney** — CC0 SFX 팩 다수: https://kenney.nl/assets

### 절차 생성
- **sfxr / jsfxr / ChipTone** — 8비트 SFX 를 슬라이더로 생성. 픽셀아트 게임과 궁합이 좋고 라이선스 부담이 없다
- 파이썬 절차 생성 — 사인/노이즈 합성 + ADSR 엔벨로프로 타격음·BGM 을 만들 수 있다. 기존 `scripts/generate-bgm.py` 관례를 따를 것

```python
# 타격음 골격: 노이즈 트랜지언트 + 감쇠 사인 바디
import numpy as np
sr = 44100
def hit(dur=0.12, f=180):
    t = np.linspace(0, dur, int(sr * dur), False)
    env = np.exp(-t * 30)
    body = np.sin(2 * np.pi * f * t) * env
    click = np.random.uniform(-1, 1, len(t)) * np.exp(-t * 400) * 0.6
    return np.clip(body + click, -1, 1)
```

### 포맷
- 웹은 **ogg** 우선 + mp3 폴백. wav 는 용량이 크다
- SFX 는 모노, BGM 은 스테레오
- BGM 루프는 **제로 크로싱에서 자른다** (안 그러면 루프마다 클릭음)
